# Git Version Control Course

In this course, you will learn how to use the Git version control system and the GitHub service from both as an individual programmer and in a team.

## Learning objectives

Version control is one of the key tools in software development. It makes it possible to restore earlier versions of software, develop several versions of software simultaneously, and involve several developers in development at the same time.

After completing the course, the student

- knows the basic concepts of the Git version control system
- can use the most common features of the Git version control system
- can use Git hosting services
- can apply branches in their own and their team's development work

## Contents

- What is version control and what is Git
- Getting started
- Basic use
- Using remote repositories and hosting services
- Branches and their use
- Version control workflows in projects
- Pull requests
- Other Git operations

## Materials

There are many guides, tutorials, and instructional videos about Git available online. The course material is largely based on Scott Chacon and Ben Straub's book Pro Git (_Chacon, Straub. 2014. Pro Git, 2nd edition. Apress. Berkeley_).

The book is freely available online at [https://git-scm.com/book/en/v2](https://git-scm.com/book/en/v2).

## Exercises
Version control is difficult to understand and learn by reading. That is why hands-on practice and experimentation are essential in this course. You should always try the commands presented in the material yourself.

All exercises are completed using Git version control. The exercises required to complete the course are marked in the material with the heading __Exercise__. The exercises build on one another, so they must be completed in the order given in the material.

In addition, you will keep a learning journal during the course.

The course assignments and submission instructions can be found in the Moodle workspace.

## Tools needed for the exercises

The Git software must be installed on every computer where you want to use it. You can download the installer from [https://git-scm.com/downloads](https://git-scm.com/downloads).

You need a programming editor to complete the course assignments. Visual Studio Code is recommended as the editor. You can download it from [https://code.visualstudio.com/download](https://code.visualstudio.com/download). You can also use any other programming editor you prefer.

The assignments completed during the course are stored in and submitted through GitHub. You need to create an account to use the service. Using the service is free, and no payment details are required for registration. You can register for GitHub at [https://github.com/](https://github.com/).
